# Expedición Académica al Museo Bagua

Visita académica de los estudiantes del Segundo Ciclo de Ingeniería Civil de la Universidad Nacional Intercultural “Fabiola Salazar Leguía” de Bagua.

Curso: Cosmogonía y Cosmología Amazónica.

Diseño y desarrollo web: Erick Javier Cruz Lizana.

## Publicación

Página pública: https://cruzlizanaerick-alt.github.io/museo-bagua/

Sitio estático listo para GitHub Pages. Los archivos están en la raíz: index.html, styles.css, app.js y la carpeta assets.

Fuente de publicación: rama main, carpeta / (root). No requiere instalación ni compilación. El archivo .nojekyll permite servir los recursos directamente.

## Recursos

Los logos y las fotografías conservan sus archivos originales. La procedencia fotográfica se documenta en assets/photo-sources.json. Las fuentes locales incluyen su licencia en FONT-LICENSE.txt.
